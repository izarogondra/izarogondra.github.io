PORTFOLIO SITE
==============
Open index.html in a browser to preview. No install or build step.

FOLDERS
  index.html              Page shell + the list of project files
  css/style.css           Colors and layout
  js/app.js               Site engine (no need to edit)
  content/site.js         Your name, bio, email, links, resume entries, Work sub-tabs
  content/projects/       One file per project
  images/                 Your artwork, photo, and resume PDF can go here

ADD A PROJECT
  1. Copy content/projects/_template.js and rename it (e.g. forest-day.js)
  2. Fill it in. Set "group" to experience, school, or personal.
  3. Add <script src="content/projects/forest-day.js"></script> to index.html
  4. Put images in images/ and point to them, e.g. "images/forest-day-cover.jpg"

HOSTING (free): upload this whole folder to GitHub Pages, Netlify, or Cloudflare Pages.
